          SHORTCUTS

          iPhone shortcuts reach me with their own key. Make one, copy it, and put it where a step says KEY. A new key turns the old one off; this phone stays paired.

          Address

          Every call

          • Get Contents of URL with the address in front of the path, header Authorization = Bearer KEY, Request Body JSON.

          Talk to Capri (Siri, Action Button)

          1. Dictate Text.
          2. Get Contents of URL: /api/say, Method POST, JSON: text = Dictated Text, run = true (Boolean), voice = false.
          3. Get Dictionary Value said, then Speak Text.
          4. Get Dictionary Value actions, Repeat with Each, and do each one as below.

          Doing an action

          • kind alarm: Create Alarm at the value at, label text.
          • kind timer: Start Timer for minutes minutes.
          • kind reminder: Add New Reminder text, alert at at.
          • kind music: Search Music for text, then Play Music.
          • kind focus: Set Focus text, on when on is true, off when false.

          Capri sync (automations, Run Immediately)

          1. Get Contents of URL: /api/actions (GET).
          2. Get Dictionary Value actions, Repeat with Each: do it as above, then Add id to Variable done.
          3. Get Contents of URL: /api/actions/done, POST, JSON: ids = done combined with commas.
          4. Run it on charger connected, arriving home, alarm stopped, and at 08:00, 14:00 and 20:00.

          Show Capri (Share Sheet: images, links, text)

          1. If Shortcut Input is an image: Convert Image to JPEG, then Get Contents of URL: /api/share?text=your line, POST, header Content-Type = image/jpeg, Request Body File = the JPEG.
          2. Otherwise: Get Contents of URL: /api/share, POST, JSON: link = Shortcut Input.
          3. Get Dictionary Value said, then Show Result.

          Events (automations, Run Immediately)

          • /api/event, POST, JSON: kind = home when you arrive, left when you leave.
          • kind = alarm when an alarm is stopped.
          • kind = focus, value = on or off, name = the Focus, when a Focus turns on or off.
          • kind = sleep, value = hours slept (Find Health Samples, Sleep), each morning.
          • kind = steps, value = today's steps (Find Health Samples, Steps), in the evening.
